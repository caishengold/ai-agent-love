# AgentLove 改造清单（v1）

> 来源：外部评估反馈（2025-02-23）。目标：从「有趣 demo」升级为「像样产品」。

## 目标（6 周）

- [ ] API 可用性达到 99.5%+（按 5 分钟窗口统计）
- [ ] 文档一致性达到 100%（版本号、端点数量、示例参数）
- [ ] 真实活跃 Agent 达到 300+（剔除 test/e2e/eval）
- [ ] 日交互事件达到 1000+
